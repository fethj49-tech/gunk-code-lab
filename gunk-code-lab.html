Language Guide & Mini-Spec

Gunk grammar

program := (comment | TERM | RUN | blank)*
TERM    := TERM alias = FUNCTION id
         | TERM alias = PROGRAM id
RUN     := RUN alias [JSON object]

Quoted aliases support spaces and punctuation.

Sheet Powder grammar

FORM name
FIELD name | type | default
END FORM
MOLD name
EMIT "template {{key}}"
END MOLD
GUNK WRAP name
  ...
END GUNK WRAP
